Character Classes

\d Any digit (0-9)
\D Not a digit
\w Word char (a-z, A-Z, 0-9, _)
\W Not a word char
\s Whitespace (space, tab, newline)
. Any character except newline

Quantifiers

* 0 or more (greedy)
? 0 or 1 (optional)
{2,5} Between 2 and 5
+? Lazy / non-greedy

Anchors & Boundaries

$ End of line / string

\B Non-word boundary

Groups & Logic

(?!...) Negative lookahead
[...] Character set

How to Use Regex Tester

  1. Enter your pattern: Type or paste your regular expression inside the slash wrappers.
  2. Toggle regex flags: Select flags like g (global), i (ignore case), or m (multiline).
  3. Paste test payload: Paste log lines, emails, code snippets, or formatted strings.
  4. Inspect captured groups: Review detailed start/end offsets and group values in the table.
  5. Export or substitute: Copy matches as JSON or use the Find & Replace feature.

Frequently Asked Questions

What regex engine is used? ▼

UtilinOne Regex Tester uses the native JavaScript ECMAScript RegExp engine running directly in your browser. All modern flags (g, i, m, s, u, d, y) are supported depending on your browser version.

Are my test strings or patterns sent to a server? ▼

No! Everything is executed 100% client-side in your browser's JavaScript sandbox. No data, logs, or secrets ever leave your machine.

Can I share my regex with teammates? ▼

Yes! Click the Share URL button at the top. It encodes your pattern, flags, and test string directly into the URL fragment without sending anything over the network.

Privacy & Security Guarantee

UtilinOne is engineered with strict zero-server data transfer principles.

  • All regular expressions and test strings are compiled and evaluated strictly in local browser RAM.
  • No telemetry, no tracking cookies, and no logging endpoints.
  • Safe for confidential API tokens, customer PII, secret keys, and proprietary log data.
